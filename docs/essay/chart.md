# 图表作文

<span class="status-reviewing">reviewing · 动态静态入口已建立</span>

图表作文的任务不是抄完所有数据，而是准确写出总体趋势、最大变化和有意义的对比。

## 动态图表首段

```text
The [bar chart / line graph / table] presents the changes in [调查对象]
from [起始时间] to [结束时间]. Overall, [总体趋势].
More specifically, the figure for [项目一] rose from [数字一] to [数字二],
while that for [项目二] fell from [数字三] to [数字四].
By contrast, [项目三] remained relatively stable during the period.
```

## 静态图表首段

```text
The [pie chart / table] illustrates the distribution of [调查对象].
Among all the categories, [项目一] accounts for the largest proportion,
at [数字]. It is followed by [项目二], which represents [数字].
By comparison, [项目三] and [项目四] make up relatively smaller shares.
```

## 第二段：原因与意义

```text
The changes shown in the chart are unlikely to be accidental.
One possible explanation is that [与题目对应的社会变化].
Another important factor is [科技、教育、政策或文化因素].
Together, these factors have made it possible for [现象或趋势] to develop.
```

## 第三段：判断与建议

```text
In view of the trend, I believe that [合理预测或总体判断].
To make the development more sustainable, individuals should [个人行动].
Meanwhile, the government and other relevant institutions need to [公共措施].
Only in this way can the benefits of [主题对象] be shared by more people
and sustained in the long run.
```

## 数据选择规则

每道题优先选择三类信息：总体趋势、最大变化、最有意义的对比。避免虚构调查来源，也不要机械套用“经济发展、科技进步、政府政策”三原因。

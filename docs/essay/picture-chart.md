# 图画加图表作文

<span class="status-reviewing">reviewing · 低频题型，已有真题验证入口</span>

> 需要直接背诵和替换的完整版本，请先看[四类大作文模板总表](/essay/template-pack)。

这类题的底层逻辑是：图表负责说明规模或趋势，图画负责呈现具体场景或现实影响，二者共同指向一个主题。

## 整合型首段

```text
The picture and the chart present the same issue from two complementary
perspectives. The chart shows that [关键趋势或核心数据].
The picture, meanwhile, depicts [人物、场景或具体行为],
which provides a vivid example of this development.
Taken together, they suggest that [中心主题].
```

如果图表变化明显，可以写：

```text
According to the chart, the number of [对象] increased from [数字一]
to [数字二] between [时间一] and [时间二].
The picture further illustrates what this change means in everyday life:
[图画中的具体影响].
```

## 第二段：共同意义

```text
The combination of the picture and the chart is thought-provoking.
The numerical increase shown in the chart may be attributed to [原因一].
More importantly, the scene in the picture reveals that [现实需求或社会价值].
Thus, the development reflected in the chart is not merely a numerical change;
it represents [更深层的社会变化].
```

## 第三段：评价与建议

```text
In my opinion, this development deserves continued attention and support.
Individuals should make proper use of [主题对象] and participate in [相关行为].
At the same time, public authorities should improve [基础设施、制度或服务].
Only when quantitative growth is accompanied by qualitative improvement
can [主题对象] produce lasting benefits for society.
```

## 关键检查

- 是否同时写到了图表和图画？
- 是否说明了二者的共同主题？
- 是否把数据变化与人物场景联系起来？
- 是否避免把两套模板机械拼接？

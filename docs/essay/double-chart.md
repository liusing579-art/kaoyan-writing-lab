# 双图表作文

<span class="status-reviewing">reviewing · 第五类低频题型，待真题测试</span>

双图表题同时提供两张图表，难点不是多写几组数字，而是判断两图的性质、共同主题和逻辑关系。资料研究显示，至少需要区分四种首段组合：

| 组合 | 首段重点 |
| --- | --- |
| 静态＋静态 | 分别写两图结构，再概括共同现象 |
| 动态＋动态 | 分别写两图趋势，再判断相似或对比关系 |
| 动态＋静态 | 用静态结构解释或补充动态变化 |
| 静态＋动态 | 用动态变化说明静态结构的背景或后果 |

## 本题型的三个硬检查

1. 两张图是否围绕同一主题？如果不能找到共同主题，就不能直接使用双图表模板。
2. 百分比是否为互斥构成、单选结果还是可多选原因？合计超过 100% 时，不能写成互斥构成比例。
3. 单位是否被准确保留？题面出现“万人”时，不得未经核验改写成 `thousand`。

## 当前教学结论

首段完成“共同主题—图表一—图表二—关系判断”，主体段解释两图之间的因果、互补或限制关系，结尾再提出个人与公共层面的行动。完整模板和原创样题填槽示范见[五类大作文模板总表](/essay/template-pack)。

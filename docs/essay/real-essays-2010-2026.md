本表覆盖 2010—2026 年英语（一）写作 Task 1 与 Task 2。为便于检索，题面以任务摘要呈现，不复制完整原题或范文；原始文件仅保存在本地受控资料目录。来源编号、读取范围和版权处理见 `data/source-index.json`。其中，“题型/可见事实”依据题面或图表记录，“主题/训练点”是研发分析，不等同于命题方给出的标准答案。

## 范围与使用方法

- Task 1 列出应用文的对象和核心交际任务；具体格式、署名、字数要求以当年原卷为准。
- Task 2 列出材料形式及最关键的可见信息。2010—2025 年大多要求 160—200 词；2026 年亦为 160—200 词。请以原题为准，不把摘要当作题面。
- “主题判断”用于安排教学和模板测试。遇到多义图画，先描述画面证据，再解释主题；不要把分析标签反写成题面事实。
- 历年真题已用来建立覆盖索引，不代表五类模板均已完成逐题成文测试。模板适配状态仍为 `reviewing`。

## 跨年观察与模板研发价值

1. **图画仍是主干，但材料形态并非单一。** 2010—2023 年以图画或图画组为主，出现标题、对话、双图对照等变体；2024 年为图画＋图表，2025 年转为表格，2026 年为调查类双图表。常见模板需要稳健处理低频材料，而非把所有题都硬套成单图。
2. **Task 1 的稳定核心是交际目的。** 招募、推荐、邀请、建议、通知、回复询问、信息说明反复出现。教学时先明确写给谁、为何写、需要对方做什么，再选择格式和语气。
3. **摘要与分析分层。** 图中人物、动作、标题、数据及任务指令属于材料事实；“文化认同”“拖延”“技术接受”等属于研发分析，适合作为可讨论的主题标签，不是官方主题定论。
4. **对模板的直接检验。** 2014、2016、2017、2020 适合测试双图关系表达；2024 检验跨材料整合；2025 检验静态/动态数据描述；2026 检验多图表关系与统计口径。至少需要针对这些代表题完成人工成文与复核，才能判断迁移质量。

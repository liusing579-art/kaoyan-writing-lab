# 大作文模板总览

## 使用方法

先识别题型，再选择首段入口。五类作文都可以使用“呈现材料—解释机制—评价与行动”的底层结构，但不能共用同一句开头。

### 三步审题

1. 材料展示了什么？
2. 材料真正强调、批评或说明了什么？
3. 这一主题为什么重要，我们应当怎么办？

### 三段功能

| 段落 | 任务 | 自检问题 |
| --- | --- | --- |
| 第一段 | 准确呈现并点题 | 我是否写出了最有信息量的细节？ |
| 第二段 | 解释原因、价值、影响或机制 | 我是否回答了“为什么”？ |
| 第三段 | 给出评价和行动 | 我是否提出了可执行而非空泛的建议？ |

## 模板使用边界

模板提供的是表达路径，不是需要逐字背诵的成文。每次套用后必须替换：主题词、材料细节、原因、影响和行动对象。

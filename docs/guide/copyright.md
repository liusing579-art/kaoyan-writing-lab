# 权限与版权保护

## 仓库权限

- GitHub 仓库建议设为 Private。
- 两位作者使用各自账号，不共享密码或个人访问令牌。
- 两位作者均可创建分支和 PR，但 `main` 需要分支保护和至少一位另一作者审核。
- 标记 `verified` 的知识条目建议要求两位作者审核。
- GitHub Actions 只使用 `contents: read`，不保存外部服务密钥。

## 原始资料保护

原始教材、范文、题图和第三方模板可能受到版权保护。仓库只保存：

- 文件名、来源 ID、读取范围和版权风险；
- 必要的短摘录或关键词；
- 原创总结、改写模板、分析和验证记录。

不要把整本教材、完整范文、整页题图或第三方模板原文提交到公开仓库或公开网站。

## 发布前检查

1. 检查 `data/source-index.json` 中的版权风险。
2. 搜索新增页面，确认没有大段原文复制。
3. 确认真题图片和范文没有随站点静态资源发布。
4. 站点公开前，将版权审查结果写入对应 PR。

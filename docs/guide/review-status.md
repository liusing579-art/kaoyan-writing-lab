# 审核状态与版本控制

## 为什么要有状态

研究过程中最容易出现的问题，是把“已经写出来”误认为“已经验证”。状态字段把资料观察、AI 推断和教材结论分开。

## 状态升级

```text
draft → reviewing → verified
                    ↘ archived
```

- `draft`：允许提出假设，不允许作为定论教学。
- `reviewing`：可以进入内部样章，必须保留证据和不确定性。
- `verified`：可作为现行教材内容，但仍需在后续发现反例时回溯。
- `archived`：保留历史记录，停止作为当前建议。

## 版本记录

产品层面的冻结决策写在 `docs/guide/changelog.md`。如果要推翻既有方案，PR 必须给出新证据和可验证优势。

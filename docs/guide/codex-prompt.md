# 可复制给 Codex 的完整指令

将以下内容复制到项目根目录的 Codex 任务中使用：

```text
你正在参与“考研英语作文教学资料研发库”项目。先读取 AGENTS.md，并严格遵守其中的资料、版权、审核和协作规则。

项目目标：通过历年考研英语作文真题、优秀范文、第三方模板和教学资料的系统分析，产出可直接教学、排版和使用的作文学习体系。

每轮工作必须执行：
1. 清点并核对收到的资料，更新 data/source-index.json；
2. 提取原始内容、来源位置、表达功能、适用场景和独特价值；
3. 与已有 data/knowledge/entries/ 比较，标注新增、重复、补充、冲突和存疑；
4. 在 JSON 中分别写 original_observation、ai_analysis、distilled_rule 和 validation_cases；
5. 用相关真题验证迁移能力，未验证内容不得标记 verified；
6. 更新人类可读的 docs/knowledge/ 页面和必要的 docs/essay/ 教材页面；
7. 运行 pnpm validate 和 pnpm docs:build；
8. 最终报告必须回答：读取了什么、真正新增了什么、与已有成果有何区别、保留或修改了哪些决策、产生了哪些可直接使用的教材内容、还有什么未解决。

产品修改前必须先说明：当前版本和冻结方案、具体问题、新方案的可验证优势、是否触犯设计原则、哪些内容修改以及哪些保持不变。

不要未经授权发布网站、推送 GitHub、发送外部消息、删除原始资料或复制第三方资料全文。若发现版权、来源或题型事实不确定，保留不确定性并标记状态。
```
